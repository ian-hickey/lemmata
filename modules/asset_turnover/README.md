# LEMMA.ASSET_TURNOVER

Asset turnover: revenue / average_total_assets for the period, the revenue generated per unit of assets.

```
=LEMMA.ASSET_TURNOVER(revenue, average_total_assets)
```

## Definition

revenue / average_total_assets, per [Wikipedia, Asset turnover](https://en.wikipedia.org/wiki/Asset_turnover).

## Example

`=LEMMA.ASSET_TURNOVER(800000, 1000000)` returns 0.8 (turns over 0.8 times).

## When not to use it

- Fixed-asset turnover, which uses only property, plant, and equipment.
- Comparing firms that define assets differently (average versus opening).
