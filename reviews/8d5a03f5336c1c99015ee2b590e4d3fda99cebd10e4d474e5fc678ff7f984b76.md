Written from the cited definition and the parameter contract only. Assumptions: All weight cells are type-checked before tolerance, so a bad cell gives #VALUE! even if tolerance is also bad. Type errors come before the negative-tolerance #NUM! check. Booleans, text and blanks all count as non-numbers. The sum and the difference from 1 are each rounded to 15 significant digits to mimic Excel precision, so 0.1+0.2+0.7 counts as exactly 1. An empty weights range sums to 0..

```python
import math

def _is_num(v):
    return isinstance(v, (int, float)) and not isinstance(v, bool)

def _r15(x):
    if x == 0 or not math.isfinite(x):
        return x
    return float('%.15g' % x)

def compute(*args):
    if len(args) < 2:
        return '#VALUE!'
    weights, tolerance = args[0], args[1]
    if not isinstance(weights, list):
        weights = [[weights]]
    vals = []
    for row in weights:
        if not isinstance(row, list):
            row = [row]
        for c in row:
            if not _is_num(c):
                return '#VALUE!'
            if isinstance(c, float) and not math.isfinite(c):
                return '#VALUE!'
            vals.append(float(c))
    if not _is_num(tolerance):
        return '#VALUE!'
    tol = float(tolerance)
    if not math.isfinite(tol):
        return '#VALUE!'
    if tol < 0:
        return '#NUM!'
    s = _r15(math.fsum(vals))
    diff = _r15(abs(s - 1.0))
    return bool(diff <= tol)
```
