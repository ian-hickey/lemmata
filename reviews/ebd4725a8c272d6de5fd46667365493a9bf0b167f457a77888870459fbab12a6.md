### 2. Independent implementation

Written from the cited definition and the parameter contract only. Assumptions: Booleans, text, blanks (None) and non-finite values are rejected with #VALUE! before the negative-tolerance #NUM! check. Floating-point noise is absorbed to 15 significant digits: differences below 1e-15 relative to the operand magnitudes are treated as zero, and both |difference| and tolerance are rounded to 15 significant digits before the <= comparison. This mimics Excel's 15-digit precision..

<details><summary>Reference code</summary>

```python
import math

def _isnum(x):
    return isinstance(x, (int, float)) and not isinstance(x, bool) and math.isfinite(x)

def _r15(x):
    if x == 0 or not math.isfinite(x):
        return x
    return float('%.15g' % x)

def compute(*args):
    if len(args) != 4:
        return "#VALUE!"
    for a in args:
        if not _isnum(a):
            return "#VALUE!"
    assets, liabilities, equity, tolerance = (float(a) for a in args)
    if tolerance < 0:
        return "#NUM!"
    rhs = liabilities + equity
    diff = assets - rhs
    scale = max(abs(assets), abs(rhs), abs(liabilities), abs(equity))
    if abs(diff) <= scale * 1e-15:
        diff = 0.0
    d = _r15(abs(diff))
    t = _r15(tolerance)
    return bool(d <= t)
```
